# Конфигуратор Avatr 07L

Только конфигуратор: без шапки, логотипа, подвала и цен. Его собирают в сборку и встраивают в страницу модели на сайте.

Посмотреть: https://tema-mail.github.io/avatr-07l-konfigurator/ (закрыт от индексации).
Локально: `python3 -m http.server 8940`, затем http://127.0.0.1:8940/

## Что выбирает человек
Версия (Elite, Max, Max+, Ultra); цвет кузова, диски, цвет салона; дополнительно – аудиосистема huawei sound, 25 динамиков, кресло пассажира «невесомость», холодильник с подогревом, электронные зеркала с камерами.
Варианты взяты из официального конфигуратора Avatr (avatr.com).

## Картинки
Официальные рендеры Avatr конкретной сборки: три вида кузова без фона (спереди, сбоку, сзади) и три вида салона.
Кузов снят для каждого сочетания версии, цвета, дисков, салона, электронных зеркал и спортивного обвеса.
Китайские надписи с кадров убраны: строка-оговорка обрезана, надпись на номерной рамке и шильдик закрашены.
150 сборок кузова, 12 вариантов салона, всё в WebP.

## Встраивание в сайт
Скопировать блок `<div class="z9" data-z9>…</div>` из `index.html`, подключить `css/konfigurator.css`,
`js/zeekr-data.js`, `js/konfigurator.js`, положить рядом папку `img/`. Движок общий для всех моделей Zeekr,
модель задаёт только `js/zeekr-data.js` и картинки. Цвета – токены `--z9-*` в начале CSS (светлая и тёмная тема).

Заявка «Отправить сборку менеджеру»: у формы атрибут `data-endpoint` – адрес приёма заявок сайта,
туда уходит POST JSON `{name, phone, text, url, lines, source, page}`. Пока он пустой, заявка уходит событием:
```js
document.querySelector('[data-z9]').addEventListener('zeekr:lead', e => send(e.detail));
// текущая сборка в любой момент: window.ZeekrCfg.get()  → {text, lines, config, url}
// каждое изменение: событие 'zeekr:change'
```
Ссылку на политику конфиденциальности вписать в `a[data-policy]` формы. Сборка хранится в адресе (`#v=55&o=…`).

## Как обновить данные
1. На сервере (у Avatr открытый API, браузер не нужен): `python3 tools/avatr_srv.py <productCarId> avatr-raw.json`,
   файл положить в `raw/avatr-raw.json`. productCarId – из адреса avatr.com/carset?productCarId=…
2. `tools/avatr-model.sh 07l "Avatr 07L" "07L"` – кадры, данные, проверки и выкладка (NOPUSH=1 – без выкладки).
   Координаты закраски надписей – MASKS в tools/avatr.py, у каждой модели свои; после сборки смотреть кадры глазами.
Движок и стили общие с конфигураторами Zeekr, мастер-копия – репозиторий tema-mail/zeekr-9x-konfigurator.
